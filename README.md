[김병식],[박민철],[박 이리나],[이종철],[이 타치아나] 시트는 수정 완료된 시트임. 해당 시트는 수정하지 말것. [김병식],[박민철],[박 이리나],[이종철],[이 타치아나] 시트를 참고하여 나머지 시트를 수정할것.

행 A~T,BH~BP는 절대 수정하지 말것.

수정해야하는 열은 U열~AE열, AG열~AI열,AN열~BG열

원본사진을 보고 판단하여 셀을 수정할 것. 해당 셀에 맞지 않는 정보가 적혀있으면 알맞는 내용으로 수정할 것. 원본사진에 적힌 파일명이 [박스번호] 및 [자료번호]와 일치해야함 
Ex)원본사진 파일명:’이 타치아나 BOX 1_01’는 행2번에 사용되는 원본사진임. 원본사진의 뒷면이 있을경우 ‘이 타치아나 BOX 1_19_01’ ‘이 타치아나 BOX 1_19_02’ 형태로 뒷번호가 붙음. 뒷면사진이 있을경우 뒷면 정보도 사용하여 셀을 수정함. 수정한 부분은 파란색 글씨로 작성함.

*필수 수정사항
U열 [*명칭] 수정사항: 원본 사진을 보고 사진 정보를 “명사-명사-명사” 형태로 작성할 것. 원본사진 뒷면이 있을경우 뒷면 정보도 참고하여 작성할 것. Ex) 가정-노인과 어린이(x) -> 가정-노인-어린이(o) / 재봉틀 앞에서 천을 다루는 여성(x) -> 재봉틀-천-여성(o)
최소 3가지 이상 명사를 적을 것. 해당 셀에 맞지 않는 정보가 적혀있으면 알맞는 내용으로 수정할 것.

Z열,AA열,AB열 [용도기능(대분류)],[용도기능(중분류)],[용도기능(소분류)] 수정사항: 원본 사진을 보고 알맞는 용도기능_코드가 들어 갔는지 확인하고 틀린 용도기능_코드가 작성되어 있을경우 맞는 용도기능_코드로 수정할 것. [용도기능_코드표는] [김병식 (2)] 시트 앞에 있음.

AC열 [일자] 수정사항: 원본 사진을 보고 알맞는 일자를 적을 것.원본사진 뒷면이 있을경우 뒷면 정보도 사용하여 작성할 것. 틀린 일자가 적혀 있는 경우 알맞는 일자로 수정할 것. 온점 없이 숫자 8자리로 입력.  Ex)20261016 일자를 정확히 알 수 없는 경우 확실하게 알 수 있는 일자까지만 작성 후 알 수 없는 일자는 0처리함 Ex)19900000 해당 셀에 맞지 않는 정보가 적혀있으면 알맞는 내용으로 수정할 것.

AD열 [일자유형] 수정사항: AC열에 적힌 일자를 보고 연도일치 / 연대추정(10년단위) / 세기추정(100년단위) / 알 수 없음 [일자유형]의 종류 4가지 중 맞는 것을 적을 것. 
띄어쓰기가 있는 [일자유형]은 '알 수 없음' 밖에 없고 나머지는 붙여쓰기 적용.해당 셀에 맞지 않는 정보가 적혀있으면 알맞는 내용으로 수정할 것.

AG열,AH열,AI열 [주소(특별시,도)],[주소(시,군,구)],[주소(상세주소)] 수정사항: 원본 사진을 보고 자료가 생산된 주소를 기술하고, 자료가 생산된 시점의 주소를 작성할 것. 원본사진 뒷면이 있을경우 뒷면 정보도 사용하여 작성할 것.해당 셀에 맞지 않는 정보가 적혀있으면 알맞는 내용으로 수정할 것.

AN열 [자료 내용] 수정사항: 내용은 간결하게 명사형 종결 형태로 작성할 것. 원본사진을 보고 정확히 알 수 있는 정보를 적을 것. 원본사진 뒷면이 있을경우 뒷면 정보도 작성할 것. 해당 셀에 맞지 않는 정보가 적혀있으면 알맞는 내용으로 수정할 것.

AO열 [원 자료 표기] 수정사항: 원본사진의 뒷면에 적힌 내용이 있을경우 해당 내용을 적을것 정확히 해독이되지 않는 언어가 나오면 “해독불가” 작성할 것. 해당 셀에 맞지 않는 정보가 적혀있으면 알맞는 내용으로 수정할 것.

BC열 [내부 근거·판단정보] 수정사항: 지금까지 수정 및 작성한 내용을 판단한 근거와 기준을 작성할 것. 내용은 간결하게 명사형 종결 형태로 작성할 것. 
Ex)장소 및 내용은 수기 목록 내용과 박물관 측에서 정리한 메타본을 바탕으로 자료 내용을 판단하여 표기함. /명칭,국적 및 자료내용은 원본 사진을 보고 판단하여 표기함.
