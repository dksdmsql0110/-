# 디지털 아카이브 메타데이터 수정 가이드

## 작업 개요

- [김병식], [박민철], [박 이리나], [이종철], [이 타치아나] 시트는 수정 완료된 시트이므로 그대로 두어야 합니다.
- 이 시트를 참고하여 나머지 시트를 수정해야 합니다.
- 원본 사진을 기준으로 정보를 판단하고, 기존 값이 맞지 않으면 적절한 값으로 수정합니다.
- 원본 사진의 파일명은 [박스번호]와 [자료번호]와 일치해야 하며, 뒷면 사진이 있으면 뒷면 정보를 함께 확인합니다.
- 수정한 내용은 파란색 글씨로 작성합니다.

## 수정 금지 범위

- 행 A~T, BH~BP는 절대 수정하지 않습니다.
- 수정 대상 열은 다음과 같습니다.
  - U열~AE열
  - AG열~AI열
  - AN열~BG열

## 기본 원칙

- 원본 사진을 직접 확인하고 판단합니다.
- 해당 셀의 내용이 원본 사진과 일치하지 않으면 수정합니다.
- 원본 사진의 파일명 예시는 다음과 같습니다.
  - 예) 원본사진 파일명: '이 타치아나 BOX 1_01'
  - 이 사진이 해당 행의 원본사진입니다.
  - 뒷면이 있을 경우: '이 타치아나 BOX 1_19_01', '이 타치아나 BOX 1_19_02'처럼 뒷번호가 붙습니다.
  - 뒷면 사진이 있으면 해당 정보를 함께 참고하여 셀을 수정합니다.

## 필수 수정사항

### 1. U열 [명칭]

- 원본 사진을 보고 사진 정보를 “명사-명사-명사” 형태로 작성합니다.
- 뒷면이 있으면 뒷면 정보도 참고합니다.
- 최소 3가지 이상의 명사를 사용합니다.
- 예)
  - 가정-노인과 어린이(x) → 가정-노인-어린이(o)
  - 재봉틀 앞에서 천을 다루는 여성(x) → 재봉틀-천-여성(o)
- 해당 셀에 맞지 않는 정보가 있으면 적절한 내용으로 수정합니다.

### 2. Z열, AA열, AB열 [용도기능(대분류)], [용도기능(중분류)], [용도기능(소분류)]

- 원본 사진을 보고 적절한 용도기능 코드를 확인합니다.
- 잘못된 용도기능 코드가 입력되어 있으면 올바른 코드로 수정합니다.
- 용도기능 코드표는 [김병식 (2)] 시트 앞에 있습니다.

### 3. AC열 [일자]

- 원본 사진을 보고 정확한 일자를 입력합니다.
- 뒷면 사진이 있으면 뒷면 정보도 함께 사용합니다.
- 틀린 일자가 적혀 있으면 올바른 값으로 수정합니다.
- 입력 형식은 숫자 8자리, 온점 없이 작성합니다.
- 예) 20261016
- 일자를 정확히 알 수 없는 경우, 확실하게 알 수 있는 범위까지만 작성하고 나머지는 0으로 처리합니다.
- 예) 19900000

### 4. AD열 [일자유형]

- AC열에 적힌 일자를 기준으로 다음 4가지 중 적절한 유형을 입력합니다.
  - 연도일치
  - 연대추정(10년단위)
  - 세기추정(100년단위)
  - 알 수 없음
- 띄어쓰기가 있는 값은 '알 수 없음'만 해당합니다.
- 나머지는 붙여쓰기 형식으로 작성합니다.

### 5. AG열, AH열, AI열 [주소(특별시,도)], [주소(시,군,구)], [주소(상세주소)]

- 원본 사진을 보고 자료가 생산된 주소를 기록합니다.
- 자료가 생산된 시점의 주소를 기준으로 작성합니다.
- 뒷면이 있으면 뒷면 정보도 함께 확인합니다.
- 해당 셀에 맞지 않는 정보가 있으면 올바른 내용으로 수정합니다.

### 6. AN열 [자료 내용]

- 내용은 간결하게 명사형 종결 형태로 작성합니다.
- 원본 사진을 보고 정확히 알 수 있는 정보를 적습니다.
- 뒷면 정보가 있으면 이를 함께 반영합니다.
- 잘못된 값이 있으면 적절한 내용으로 수정합니다.

### 7. AO열 [원 자료 표기]

- 원본 사진 뒷면에 적힌 내용이 있으면 해당 내용을 작성합니다.
- 정확히 해독되지 않는 언어가 나오면 “해독불가”로 작성합니다.
- 해당 셀에 맞지 않는 정보가 있으면 수정합니다.

### 8. BC열 [내부 근거·판단정보]

- 지금까지 수정 및 작성한 내용을 판단한 근거와 기준을 간단하게 작성합니다.
- 내용은 간결하게 명사형 종결 형태로 작성합니다.
- 예)
  - 장소 및 내용은 수기 목록 내용과 박물관 측에서 정리한 메타본을 바탕으로 자료 내용을 판단하여 표기함.
  - 명칭, 국적 및 자료내용은 원본 사진을 보고 판단하여 표기함.

## 최종 체크포인트

- [김병식], [박민철], [박 이리나], [이종철], [이 타치아나] 시트는 수정하지 않습니다.
- 원본 사진과 파일명, 번호, 뒷면 정보가 일치하는지 확인합니다.
- 수정 대상 열만 정확히 반영합니다.
- 값이 잘못 입력되었으면 원본 사진을 기준으로 수정합니다.
